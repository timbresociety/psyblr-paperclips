# Visual and brand contract

## Intended feel

Minimal, luxurious operational UI around rich tactile game objects. The interface should feel like a compact machine operated by a capable founder, not a SaaS analytics dashboard, crypto terminal, spreadsheet or generic sci-fi cockpit.

Use strong typography, whitespace, stable numeric instrumentation and one visually dominant work object in the center.

## Composition

Stable perimeter:
- top: valuation, ARR, cash, time and critical survival state;
- navigation: six work functions with compact queue/agent state;
- side/edge: alerts, obligations and causal history;
- center: the current tactile work object or a management object the player deliberately opened.

Do not make every region an equally weighted rounded card. The center should clearly win the hierarchy.

Routine alerts never cover active play. The alert inbox has one stable home and escalates through count, motion, contrast and sound rather than surprise modals.

Mobile is recomposed, not a shrunk desktop. Preserve the active gesture area and thumb reach before secondary instrumentation.

## Brand geometry and references

Use the supplied `public/references/structure-monogram-primary.png` as the primary mark. Do not redraw an approximate luxury monogram. `structure-spark-monogram-family.png` shows the secondary Spark relationship.

Reference images are principle evidence, not layouts to copy:
- `pastel-ethereal-environment.png`: aspiration/milestone atmosphere; pale cyan/lavender/blush, reflective depth, monumental scale. Keep it out of dense active gameplay.
- `contextual-3d-icon-family-airbnb-reference.png`: isolated contextual 3D object semantics and dimensionality only. Do not copy the shown brand's objects or layout.
- rarity texture images: material progression only. Ethereal is the apex, physically convincing iridescent liquid metal rather than CSS rainbow/glitter.

## Typography

Readable UI grotesk, deliberate display hierarchy and tabular financial numerals. Inter/Inter Tight are practical fallbacks. Avoid tiny “luxury” labels, fake sci-fi type and all-caps paragraphs. Amount changes must not shift adjacent controls.

## Objects and icons

Final semantic icons should be original contextual 3D objects with transparent backgrounds, strong silhouettes and coherent camera/lighting. Use materials because they communicate meaning, not because liquid metal is fashionable. No emoji or generic flat icon family as final language.

## Motion and sound

Every major action should have anticipation → commitment → response → resolution → control returned.

Starting motion ranges:
- micro response: 80–140ms
- local state change: 180–260ms
- panel: 220–320ms
- major reward: 500–900ms

Input acceptance never waits for ornamental animation. Reduced motion preserves meaning through state/contrast.

Audio should be tactile: concise clicks, resisted contacts, magnetic snaps, short compression, restrained financial ticks. Avoid casino jingles and constant alarms.
