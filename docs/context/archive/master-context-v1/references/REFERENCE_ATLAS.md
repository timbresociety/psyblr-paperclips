# Reference atlas

These local images are evidence for principles, not instructions to copy a third-party execution.

## Founder-supplied / brand references

- `structure-monogram-primary.png`: primary Structure silhouette, curve language and negative-space geometry. Do not redraw a similar luxury mark.
- `structure-spark-monogram-family.png`: relationship between Structure and Spark. Spark is proprietary brand punctuation, not a generic sparkle icon.
- `contextual-3d-icon-family-airbnb-reference.png`: contextual object semantics, isolated object readability and dimensional image-icon integration. Do not copy the shown brand's exact objects, layout or name.
- `pastel-ethereal-environment.png`: Sky atmosphere, monumental scale, pale cyan/lavender/blush, reflective depth and aspiration. Do not put this image behind dense active gameplay or clone its composition.
- `rarity-texture-charcoal-stone.png`, `rarity-texture-shiny-gold.png`, `rarity-texture-translucent-liquid-glass.png`: examples of semantically directional lower rarity surfaces.
- `rarity-progression-enlightenment-example.png`: material progression principle. Its names, APY copy, cards and layout are not SoloUnicorn content. Ethereal is the apex.

## External principle references

- Paula Scher/Pentagram: identity hierarchy, typography, scale and memorable systems.
- Monotype: typography as infrastructure, numeric consistency and responsive legibility.
- Milkinside/Gleb Kuznetsov: interaction-first product/motion authorship, purposeful motion and one emotional beat per major flow.
- Game Design Library: mechanic clarity, mastery, tempo, risk/reward, causal feedback and systemic consequence.
- Liquid-metal references: Ethereal surface behavior only.
- PSYBLR editorial atmosphere: Sky mood only.

Before using any reference ask: What exact property does it teach? What does it not teach? Am I extracting a principle or copying an execution? Does the result remain original and mechanically readable?
