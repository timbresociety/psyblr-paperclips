# Asset briefs and escalation path

## Standard contextual 3D icon

Create a custom hyperrealistic 3D object on a transparent background. Use one dominant silhouette, controlled perspective, baked self-shadow/ambient occlusion, clear rim/edge separation and enough negative space to read at small size. Choose the object from:

```product meaning → culturally resonant object → durable/nostalgic object → original coherent fusion → premium art direction
```

Do not use emoji, stock flat icons, stock 3D libraries, text baked into the image, opaque UI cards or forced gold/glass/Ethereal materials. Material follows the object's meaning.

For each request record: destination, semantic meaning, object fusion, camera, material, light, transparent output, pixel sizes, state variants and prohibited substitutions. Review as a family sheet.

## Rarity-bearing asset

Define why the object transforms at each tier. Lower materials can be charcoal/stone, gold, liquid glass or another meaningful sequence. The apex is Ethereal: physically convincing iridescent liquid metal with restrained spectral shift and preserved form. Do not implement Ethereal as CSS rainbow or generic holographic foil.

## If generation is unavailable

Create `asset_requests/pending/<stable-id>.md` with the exact semantic object, silhouette, camera, materials, lighting, transparency, size variants, state behavior and acceptance test. Keep development fixture separate and visibly non-final. Never silently replace a missing final asset with emoji or stock icons.
