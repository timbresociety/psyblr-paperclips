# SoloUnicorn master context pack

Use `00_START_HERE.md` as the entry point. This is the consolidated product, design, content, engineering, agent-execution and quantitative-engine context for the one-person founder roguelike.

The folder is intentionally split into authoritative domains:

- `CONTEXT.md` defines the founder fantasy, six operating functions, Finance role, attention model, progression and successful-founder meta.
- `engine/` defines the 244-metric candidate profile, formulas, schemas, event order, reference reducer and checks.
- `DESIGN.md`, `SCREENS.md`, `CONTENT.md` and `GAME_DESIGN.md` define presentation, interaction, writing and decision quality.
- `ENGINEERING.md` defines the deterministic React/Canvas/PWA implementation boundary.
- `BUILD_PLAN.md` and `data/delivery_plan.json` define bounded delivery outcomes.
- `TERMINAL_AGENT.md` and `terminal/` define cost-aware coding-agent execution.
- `references/` contains the supplied visual references and their interpretation limits.

Run:

```bash
python3 scripts/check_master.py
python3 engine/verify.py
```

The profile is numerically specified and reference-tested, not full-run play-balance validated. Relic balance is intentionally a later evaluation. Successful repeat founders retain their earned advantages; the pack does not normalize or cap them to preserve first-run difficulty.
